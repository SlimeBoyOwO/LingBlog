# 🐈✨ LingChat - 灵动の人工智能聊天陪伴助手

一个能记住你、懂你情绪、用声音和画面陪你谈心的高自由度虚拟恋人系统。

## 🚀 快速开始

- [💻 开发文档](./develop/) - 了解项目结构和开发流程

## ✨ 核心功能

| 功能          | 描述                                  |
| ------------- | ------------------------------------- |
| 🔍 永久记忆   | 内嵌RAG技术，实现信息持久存储         |
| 🧠 情绪分类   | 自训练模型实时识别AI情绪              |
| 🎭 灵动面板   | 表情、动作和气泡颜色随对话实时变化    |
| 💾 双档回溯   | 非RAG存档，支持无限历史回溯           |
| 🎧 VITS耳语   | 提供真实语音和耳语音效                |
| 🎨 自定义角色 | 可上传OC或游戏角色，自由搭配背景与BGM |
