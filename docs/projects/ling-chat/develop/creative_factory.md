# 创意工坊上传指南

## 1. 准备工作

你可以上传任何你的创意到创意工坊，我们的创意工坊在项目的讨论区，你可以直接点击[这里](https://github.com/SlimeBoyOwO/LingChat/discussions)访问。

## 2. 上传步骤

### 2.1. 创建讨论

在讨论区点击`+ New discussion`，你会进入`Select a discussion category`界面，在这里选择你要上传的类型，如`新人物`，`剧本`等。点击对应部分的`Get Started`，就可以开始编写你的创意工坊内容了。

### 2.2. 编写内容

为了让你的内容在程序的创意工坊能更好的显示，你需要按照下面的格式编写你的内容：

```md
# 人物展示

![头像](https://github.com/user-attachments/assets/c064efff-dec8-4dcc-8204-167abf25ee65)

## 相关信息

是心奈教官，才不是心奈酱！
请 sensei 把我当成熟的淑女哦

## 标签

GSV语音 碧蓝档案 多服装 新版

## 使用说明

把文件夹“心奈”拖入game_data/characters中后，刷新人物列表即可使用。
**本人物使用GSV的模型，如果要使用语音请下载对应的语音模块**

[心奈.zip](https://github.com/user-attachments/files/31038562/default.zip)
[碧蓝档案语音模型链接](https://pan.baidu.com/s/1n4lv4c_0Ha9PKgdZdEKEaA?pwd=7jg1)

## 说明

人物素材来自于《碧蓝档案》禁止商用。
```

- **人物展示/剧本封面展示**：在这里，提交一个封面，在创意工坊中会选取你的图片作为展示。
- **相关信息**：在这里，你可以写一些关于你的创意的介绍，如人物背景、使用说明等。
- **标签**：这里程序会显示你上传的创意的标签，方便用户查找。
- **使用说明**：在这里，你可以写一些关于如何使用你的创意的说明，如如何安装、如何使用等。
- **其他**：想怎么写就怎么写，前面的部分满足即可。

### 2.3. 提交

写完之后，点击`Submit new discussion`，你的创意就会出现在创意工坊中了捏~
