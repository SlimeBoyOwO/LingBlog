# 云端语音克隆使用指南

> 适用版本：含「语音克隆 TTS」面板的桌面/移动端版本（设置 → **TTS 设置**）。

## 1. 介绍

**云端语音克隆**让 LingChat 内置的语音合成（TTS）不再局限于预设音色：上传一段 10~20 秒的清晰人声样本，即可在云端复刻出专属音色，之后 AI 角色的每一句回复都用这个声音朗读。

- **底层服务**：阿里云百炼 **CosyVoice**（DashScope API）。软件内置完整客户端：音色注册、审核状态轮询、试听、删除，以及对话时的实时合成。
- **与本地 TTS 的分工**：本地 TTS 引擎（SBV2 等）离线运行、免费；语音克隆走云端，**需要 DashScope API Key 与网络**，合成按量计费。两者在角色语音设置中按「TTS 类型」区分选择，互不影响。
- **数据流**：注册 = 样本上传到云端临时空间 → 提交复刻任务 → 人工/自动审核（异步）；合成 = 每句对话文本发往云端 → 返回音频 → 软件播放。

```
样本音频 ──上传──▶ 云端审核 ──▶ 音色可用（voice_id）
                                  │
角色设置引用 voice_id ◀───────────┘
                                  │
AI 回复文本 ──▶ 云端合成（CosyVoice-v3.5-flash + voice_id）──▶ 播放
```

**完整的使用链路分两步**（先全局注册音色，再给角色绑定）：

1. 在 **设置 → TTS 设置 → 语音克隆 TTS** 面板：填 API Key → 上传样本 → 注册 → 等审核通过
2. 在 **角色语音设置**：把该角色的 TTS 类型选为「语音克隆 TTS」，云端音色选刚注册的那条 —— 保存之后 AI 以该角色说话时即用克隆音色发声

## 2. 快速上手

**前置**：阿里云 DashScope API Key。

**注册阿里云千锤百炼API**
- 阿里云百炼官网:https://bailian.console.aliyun.com
- 登录阿里云百练平台后在常用功能中找到**API Key**创建自己的API key
- 新用户有一定的免费试用额度，可以免费试用，额度用完后找到**费用与成本**界面进行充值即可

### 第 1 步：填入 API Key

1. 打开 LingChat → **设置 → TTS 设置**
2. 向下滚动到 **「语音克隆 TTS」** 区块
3. 在 API Key 输入框粘贴 `sk-` 开头的 Key → 点 **保存**，按钮变为「API Key 已配置 / 更换」

### 第 2 步：导入并注册第一条音色

1. 在「导入音色」小节填写 **音色名称**（必填，≤32 字符，建议用角色名）
2. **参考音频语言** 选与样本一致的语种（中文样本选「中文」，默认即中文）
3. 点 **选择语音样本**，挑一段录音（建议 10~20 秒，见[第 3 章](#register)的样本规范）
4. 点 **导入并注册音色**——按提示依次显示「上传语音样本中… → 提交复刻任务… → 已提交，等待审核…」

### 第 3 步：等待审核通过

- 提交成功后，新音色出现在「我的音色」列表，状态为黄色 **「审核中…」**；页面每 5 秒自动查询一次，无需手动刷新
- 审核通过 → 状态变绿色 **「可用」**（通常几分钟到几十分钟，取决于阿里云审核队列）
- 审核失败 → 红色「审核失败」（下方会出现「重查状态」按钮）

### 第 4 步：试听验证

1. 在「试听」小节输入一句话（如「你好，很高兴认识你」）
2. 音色下拉选择刚注册的音色 → 点 **生成并播放**，几秒后自动播放合成音频

### 第 5 步：绑定给角色

1. 进入角色的语音设置（角色详情/编辑 → 语音区），把 **TTS 类型** 改为 **「语音克隆TTS」**
2. 设置语音语言
3. **云端音色** 下拉选择刚才注册的音色（显示为 `名称 (voice_id)`）
4. 回到聊天：让该角色说话，此时听到的即为克隆音色

> 💡 想让角色用某地方言说话？中文音色可在角色设置里选**中文方言**（如四川话），见[第 5 章](#dialect)。

## 3. 进阶使用：注册一条好音色 {#register}

音色质量 ≈ 样本质量。注册表单下方的提示原文：

> 时长建议 10–20 秒，支持 wav / mp3，采样率不低于 16kHz，所选参考音频语言必须与实际音频语言一致，单人清晰说话，无背景音乐或噪音

**样本规范细则与建议**：

| 项目 | 要求 | 建议 |
|---|---|---|
| 时长 | 建议 10~20 秒 | 过短（<5s）复刻不完整；过长无益且审核更久 |
| 格式 | wav / mp3 / flac | 手机/电脑录音导出即可 |
| 采样率 | ≥16kHz | 录音软件默认 44.1k/48k 均满足 |
| 大小 | ≤20MB | 超限后端直接拒绝并提示当前大小 |
| 内容 | 单人、清晰、无 BGM/噪音 | 手机录音远离嘈杂环境；环境噪音大时开降噪或换安静房间 |
| 语言 | 必须与下拉所选一致 | 选错会直接导致审核失败或音色说话不自然 |

**音色名称与身份**：名称仅用于本机展示（保存于本地配置）；真正生效的是云端返回的 `voice_id`（格式如 `cosyvoice-v3.5-flash-<拼音前缀>-<唯一标识>`）。同一 API Key 下的不同角色可**共享同一条克隆音色**——无需为每个角色重复注册。

**注册与审核的幕后流程**：

1. 样本先上传至 DashScope 临时存储（OSS，48 小时有效），换取临时链接
2. 后端以 `create_voice` 提交复刻任务（携带音色名 ASCII 前缀、语言提示）→ 立即返回 `voice_id`，无需等待
3. 云端异步审核，状态机：`deploying`（审核中）→ `ok`（可用）/ `undeployed`（失败）
4. 软件本地缓存状态并 **5 秒轮询**；关闭设置页也没关系——轮询只发生在打开面板时，**之后试听/对话使用前会自动再查一次云端**（自愈检查），所以审核期间完全可以离开，稍后回来音色已是「可用」

## 4. 进阶使用：把克隆音色绑定给角色 {#role-binding}

在角色语音设置中：

**TTS 类型 → 选择语音克隆TTS**

**语音语言（voice_lang）**：决定 AI 回复用哪种语言朗读（含译文兜底逻辑）。语音克隆可选：中文 / 英语 / 日语 / 韩语 / 德语 / 法语 / 俄语 / 葡萄牙语（界面仅展示这 8 项；官方另支持泰/印尼/越南语，界面暂未开放选项）。**注意**：西班牙语、阿拉伯语不在 CosyVoice 支持范围（角色页也不会在语音克隆下显示这两项）。

**云端音色**：下拉列出你在 TTS 设置里注册的全部音色，显示 `名称 (voice_id)`。尚无任何音色时显示「暂无云端音色，请先到设置页注册」。

**合成行为**（绑定后的实际运行）：

- 角色每句回复在播放前实时请求云端合成（长回复按情绪/句子分段并发合成后拼接，语速自然）
- 合成参数固定：WAV 24kHz、音量 50、语速 1.0、音调 1.0
- **合成使用的模型与该音色注册时绑定的模型一致**（目前为 `cosyvoice-v3.5-flash`），软件自动取音色的注册模型，不会传错
- 若角色的语音语言为中文且配置了方言 → 合成时自动附加方言指令；为非中文语言 → 自动带上目标语言提示提升效果
- 云端网络异常/审核未过/API Key 失效时该角色的语音会静默降级（跳过语音、只出文本），并在日志中记录原因——不会阻塞对话本身

**切换与生效**：所有语音设置改动即时生效（无需重启），切换 TTS 类型后说一句话即可验证。

## 5. 进阶使用：语言与方言 {#dialect}

### 中文方言（15 种 + 普通话）

角色语音语言为**中文**且 TTS 类型为语音克隆时，「中文方言」下拉可选（默认普通话）：

广东话、东北话、甘肃话、贵州话、河南话、湖北话、江西话、闽南话、宁夏话、山西话、陕西话、山东话、上海话、四川话、天津话、云南话

方言通过合成指令触发（复刻音色必须带指令才输出方言口音），选择后 AI 的中文回复即带该方言腔调。对话文本本身仍是普通话书面语，方言体现在口音。

### 支持语言总表

| 场景 | 支持范围 |
|---|---|
| 注册样本语言（11 项下拉） | 中文 / 英语 / 日语 / 韩语 / 法语 / 德语 / 俄语 / 葡萄牙语 / 泰语 / 印尼语 / 越南语 |
| 角色朗读语言（界面 8 项） | 中文 / 英语 / 日语 / 韩语 / 德语 / 法语 / 俄语 / 葡萄牙语 |
| 不支持 | 西班牙语 / 阿拉伯语（选择时界面不会提供） |

> 样本注册时选择的语言是**复刻依据**（它决定克隆出来的音色说哪种语言最自然），角色绑定时的语音语言是**朗读目标**。样本录中文、角色说日语也可行（CosyVoice 跨语言复刻），但音色质量以样本语言最佳——实际体验为准。

## 6. 进阶使用：音色管理 {#manage}

「我的音色」列表每条记录显示：名称、`voice_id · 注册模型`、状态徽标，右侧两个操作：

| 操作 | 行为 |
|---|---|
| ▶ 试听 | 用该音色**所属注册模型**即时合成当前试听文本并播放（需先输入试听文本） |
| 🗑 删除 | 弹窗确认「云端与本地记录将一并移除」；确认后调云端删除接口并移除本地记录——云端删除失败不阻断本地移除（防云端接口异常时本地列表卡死） |

**状态徽标**：

| 状态 | 颜色 | 说明 |
|---|---|---|
| 可用 | 绿 | 审核通过，可试听/绑定使用 |
| 审核中… | 黄 | 每 5s 自动轮询，通过后自动转绿 |
| 审核失败 | 红 | 重新录制合规样本后再次注册 |
| 状态未知 | 灰 | 查询失败（多为网络问题），点「重查状态」手动再查 |
| （无状态） | 灰 | 异常旧记录，同样以重查为准 |

**本地记录说明**：音色列表保存在本机配置（settings.json）。重装或迁移设备后列表为空，但云端注册过的音色不会消失——在 TTS 设置重新导入注册同一条样本即可（会产生新的 voice_id；旧的云端音色如不再需要可先删除）。

## 7. 常见问题处理 {#faq}

| 症状 | 原因与解决 |
|---|---|
| 「API Key 未配置」/ 注册表单全部禁用 | 先在上方输入并保存 DashScope API Key；Key 已配置状态下输入框锁定，点「更换」可重新填写 |
| 上传样本超 20MB | 压缩/截取样本；wav 可转 mp3 大幅缩小 |
| 一直显示「审核中…」 | 属正常：审核异步进行，页面 5 秒轮询，通过后自动变「可用」。长时间未通过可关闭页面稍后再看（使用时自愈会实时查云端） |
| 显示红色「审核失败」 | 多为样本不合规：背景噪音/音乐、多人说话、时长过短、**参考语言与音频实际语言不一致**。录制合规样本后重新注册一条 |
| 状态「状态未知」+ 重查按钮 | 上一次查询网络失败，已自动暂停轮询；点「重查状态」手动恢复 |
| 试听报「音色尚未可用」 | 该音色缓存状态非 ok，系统已实时查云端；确认云端状态确为失败则需重新注册 |
| 角色聊天没有语音（绑定了克隆音色） | 按序检查：① API Key 是否配置且正确 ② 音色状态是否为「可用」③ 网络可达 dashscope ④ 角色语音语言是否在支持列表。TTS 服务异常时对话会跳过语音正常出文本，不会卡住 |
| 角色语音不是目标方言 | 方言仅语音克隆 + 语音语言为中文时生效；确认两处都已设置并保存后重新触发一句回复 |
| 说话像机器人/口音怪 | 合成本身质量尚可的情况下，多为注册样本质量或样本语言与角色朗读语言差异导致；换一段更清晰的样本重新注册对比 |
| 删除音色后角色还在用 | 该角色的云端音色字段指向已删除音色，其语音将不可用——重新注册音色并在角色语音设置里改绑 |
| 想给多个角色用同一个声音 | 注册一条即可：多个角色绑定同一条云端音色（云端音色全局共享，不随角色删除而消失，除非在 TTS 设置里主动删除） |
| 费用与隐私 | 合成与音色注册按阿里云官方计费（以百炼控制台价格为准）；**上传的样本与合成文本会发送至阿里云**，敏感内容勿用于云端克隆；克隆他人（真人）声音请先取得授权，删除音色可移除云端副本 |
| 移动端注册音色 | 支持：文件选择走系统文件（SAF），wav/mp3/flac 均可用，行为与桌面一致 |

## 附：术语对照

| 术语 | 含义 |
|---|---|
| CosyVoice | 阿里云通义语音合成服务（含声音复刻能力），本文所有云端能力基于它 |
| DashScope | 阿里云模型服务开放平台（百炼），API Key 在此获取 |
| 复刻 / 克隆音色 | 用一段参考人声样本训练出的专属音色，用 `voice_id` 标识 |
| voice_id | 云端音色唯一标识，形如 `cosyvoice-v3.5-flash-<前缀>-<编号>`；注册时生成、合成时引用 |
| 注册模型 | 音色创建时绑定的合成模型（当前固定 `cosyvoice-v3.5-flash`），试听/合成必须同模型 |
| 审核（deploying/ok/undeployed） | 阿里云对音色样本的异步审核状态；软件 5 秒轮询 + 使用前自愈复查 |
| language_hints | 合成时的目标语言提示（提升非中文朗读效果） |
| instruction（方言指令） | 复刻音色的方言触发指令（如「用四川话说话。」），仅中文场景使用 |
