# 🌍【LingChat开发】征召令：开源贡献与星辉奖励机制说明 v1.0

> **来自超级LingChat真理部的最高指令：**
>
> 我们的代码库正在遭受 **Bug 终结族** 和 **需求机器人** 的猛烈进攻！前线紧缺支援！
>
> 为了捍卫代码的优雅与架构的民主，现正式发布**【开源星辉系统】**。所有参与 GitHub/群需求 任务并成功撤离的开发者，将根据任务难度与完成质量，被授予**【创作星辉点数 (Contribution Starlight Points, CSP)】**。
>
> _点数可用于兑换软妹币补给、开发者周边或真理部特供礼品。_

---

## 🎖 星辉结算核心机制

我们的奖励计算公式如下：

$$
\text{最终奖励 (CSP)} = \text{基础难度分 (Base)} \times \text{星级倍率 (Multiplier)}
$$

### 2. ⭐ 任务完成星级

任务不仅仅是“做完”，更要“做好”。你的代码质量决定了最终的**倍率**。

#### ⭐ 任务完成 (Completed) - `x 1.0`

> _"虽然有些波折，但你活着回来了。"_

- **标准：**
  - 功能符合需求，无明显 Bug。
  - **代码通过 Code Review (CR)**：符合项目规范，无低级错误。

#### ⭐⭐ 表现不错 (Great) - `x 1.2`

> _"你不仅完成了任务，还带回了样本。"_

- **标准：**
  - 满足所有“任务完成”标准。
  - **完成了 Issue 中提及的“额外挑战 (Bonus)”**。
  - 代码结构非常优雅，逻辑清晰，易于维护，方便扩展。
  - **极少 CR 修改**：代码质量极高，PR 一次性通过或仅有极少量非逻辑性修改。

#### ⭐⭐⭐ 完美执行 (Perfect) - `x 1.5`

> _"这是绝地潜兵的教科书式胜利！超级地球为你骄傲！"_

- **标准：**
  - 满足所有“表现不错”标准。
  - **超预期交付**：你自己扩展了相关功能，极大提升了用户体验。
  - **极致优化**：性能提升显著，或解决了连管理员都没发现的潜在隐患。

### 💰 结算示例

假设你领取了一个 **N4 (挑战级)** 的任务：_“重构角色配置表单，支持动态 Schema 生成”_（基础分 100）。

- **情况 A：** 你只是把功能做出来了，但代码里有一堆硬编码，经过 3 轮 CR 才改好。
  - 结算：`100 (N4) * 1.0 (完成) = 100 CP`
- **情况 B：** 你不仅做好了，还封装了通用的表单组件，并支持了语音配置的联动显示。
  - 结算：`100 (N4) * 1.2 (不错) = 120 CP`
- **情况 C：** 在 B 的基础上，你还优化了加载动画，写了详细的开发文档，并且代码极其优雅，管理员直呼内行。
  - 结算：`100 (N4) * 1.5 (完美) = 150 CP`

## 🚀 如何参与（作战手册）

1.  **接取任务**：
    前往 [GitHub Issue 列表](https://github.com/SlimeBoyOwO/LingChat)，寻找带有 `Status: Help Wanted` 标签的任务。
    在 Issue 下方评论或和管理员QQ联系自己可以做的相关言论之后。管理员分配给你后即视为接取成功。

2.  **执行任务**：
    - Fork 仓库，创建新的分支。
    - 遵循代码规范（请阅读 `CONTRIBUTING.md`）。
    - **切记**：我们重视**可维护性**。不要写“一次性代码”。

3.  **提交代码**：
    提交 Pull Request (PR)，关联对应的 Issue。

4.  **代码审查 (Code Review)**：
    这是最关键的一步。管理员会对代码进行审查。**只有通过审查的代码才能合并并结算奖励。**
    - _提示：请耐心对待 CR 意见，这是提升技术能力的最佳机会。_

5.  **战勋结算**：
    PR 合并后，管理员会在评论区根据上述规则进行结算评分，并记录你的 CSP。
