# LingChat 0.4.0 更新日志

## 一、工作总结

相比于 LingChat 0.3.0，我们完成了十分多出色的成就，项目也慢慢从稚嫩走向成熟，以下是一份简单的总结：

### 1. 🎉 本次更新功能

#### 1. 【主要更新】剧本模式实装：

- 现在可以导入任意剧本，实现在剧本模式下的多人物对话，和人物的羁绊与冒险了！

#### 2. 日程与番茄钟功能：

- 可以通过安排日程，让AI了解自己的日程安排，以此作为主动对话的引导，在此记录代办和提醒，并为重要的日期（比如节假日有特殊对话等）提供特殊的高互动
- 可以像是 Lofi 一样，在 LingChat 运行番茄钟，作为自己的工作伙伴

#### 3. 角色卡功能的扩充：

- 现在可以定制角色的可触摸部分和触摸反馈效果。
- 现在可以为角色定制额外的服装，并切换角色的服饰。
- 角色卡由 txt 转换为 yaml 文件，支持更高的扩展性。
- 现在角色卡还能有自己的专属报错和信息提示。

#### 4. 全新的 UI 界面：

- 新版本实装了主界面，剧本选择界面，还额外新增了制作者感谢页面等。
- 新的 UI 界面更加美观，简洁，并且在性能和优化上相比之前有巨大的提升
- 新的 UI 界面支持手机端优化
- 新的 UI 界面提供了便捷的菜单栏，支持快速查看对话历史，使用触摸功能等。
- 现在增添了许多额外的粒子效果，帮助对话更沉浸式。

#### 5. 全新的永久记忆方案与存档的联动

- 现在存档本身具有永久记忆功能，可以通过打开永久记忆功能压缩存档内角色的记忆，并以记忆仓库的形式记录。
- 永久记忆不再是全局单一，每个角色每个存档都有属于自己的永久记忆，并且现在使用数据库存储，更加优雅

#### 6. 第 19 情绪 - 平静

- 优化了 Bert 情感模型的数据集，达到了更高的准确率和 F1 Score，现在支持识别困倦，冷淡之类“平静”的情绪。

#### 7. 新增的许多便利小功能：

- 现在可以自动对话，方便懒得点击的玩家。
- 读取存档的时候会自动同步过往的对话历史，方便快速回顾。
- 对话历史现在可以播放语音，享受奇奇喵喵的音叫。

#### 8. 自主对话功能：

- 通过读取时间，日程，代办，特定的节日或日期，AI 可以主动发起对话，主动窥屏了解玩家等，提供更加随机和真实的陪伴感。
- 玩家可以自由设定触发条件以及频率，提供更加个性化、智能的陪伴体验。

#### 8. 成就系统：

- 程序内实装了成就系统，可以完成特定任务触发成就。

#### 9. 小版本自动更新功能：

- 现在可以自动更新小版本，并且可以设置自动更新。

### 2. 🌸 性能优化与提升

#### 1. 异步对话综合性能提升

- 使用异步与消息队列，将原来需要相应15s的对话提升到1~2s内，大幅提升了对话节奏和性能。

#### 2. 前端角色立绘与背景丝滑切换与美化

- 现在角色立绘切换的时候，会有淡入淡出的过渡效果，背景也一样。
- 因为前端被完全重构了，所以在任何细节上都变得更加丝滑好看了。
- 新增鼠标移动的粒子效果，点击的粒子效果。

#### 3. 移除 pytorch，大幅优化内存占用

- 使用 onnx 替代 pytorch，使 LingChat 本体直接减少 2GB 内存占用，并且大幅提升推理性能。
- 额外的，对于 Style Bert Vits2，大小优化上从 25GB 压缩到了 1.5GB

#### 4. 支持多客户端同时运行

- 现在可以手机，电脑同时运行，并且互不干扰。同时全局播报的事件会发送给所有登录的设备上。

### 3. 🌈 本体内容新增

#### 1. 默认角色升级和增加

- 钦灵的所有立绘差分人工重绘，变成了全身立绘形态。
- 新增默认角色风雪，阔爱的冷静猫娘，魔法师desu

#### 2. 大量背景素材和人物NPC

- 新增大量背景素材和人物NPC，卷大人牛逼。

### 4. 🔧 Bug 修复与改进

- 修复了一些跨平台的问题。
- 修复了大量，过往的 bug。（由于完全重构所以以前的bug很难再触发了）
- 修复了许多关于 LLM 无法调用的问题，并提供了Gemini的代理服务接口。
- 提供翻译和原话分离 LLM 的策略，防止翻译和原话混淆。

### 5. 🧪 实验性功能与新项目扩展

#### 1. LingPal 桌宠项目

- 使用 Tauri + Vue 开发，目前仍在开发阶段，本桌宠可以在桌面上运行，是一个独立的程序窗口，并且可以和主 LingChat 联动记忆，更棒的是支持更精准的读取屏幕，更方便的屏幕互动等。由于开发内容较大，目前只有预览。

#### 2. LingChat - ScriptEditor 剧本编辑器

- 本剧本编辑器不亚于写一个完整的 Galgame 编辑器的工作量。不过目前已经有非常好的 Demo 效果，期待进一步的开发和完善。

### 6. 📝 文档与教程

- 新增了创建角色，安装语音的教程。
- 在 LingBlog 上，增加了大量关于项目原理的文档。
