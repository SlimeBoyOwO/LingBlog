# 程序员奇奇怪怪缩写词合集

## 1. 通用常用缩写词

| 缩写词      | 全称                                               | 含义                 | 口语/真正含义  |
| ----------- | -------------------------------------------------- | -------------------- | -------------- |
| API         | Application Programming Interface                  | 应用程序编程接口     | 接口           |
| ASCII       | American Standard Code for Information Interchange | 美国信息交换标准代码 | 字符           |
| MVP         | Minimum Viable Product                             | 最小可行产品         | 能用的史山     |
| ORM         | Object Relational Mapping                          | 对象关系映射         | Map            |
| OOP         | Object Oriented Programming                        | 面向对象编程         | 面向对象       |
| SQL         | Structured Query Language                          | 结构化查询语言       | 数据库查询     |
| Restful API | Representational State Transfer                    | 表现层状态转化 API   | 标准API设计    |
| CI/CD       | Continuous Integration/Continuous Delivery         | 持续集成/持续交付    | 构建程序       |
| CRUD        | Create, Read, Update, Delete                       | 增删改查             | 基操勿6        |
| i18n        | Internationalization                               | 国际化               | 多语言         |
| l10n        | Localization                                       | 本地化               | 本土+英语      |
| NLP         | Natural Language Processing                        | 自然语言处理         | 让机器理解语言 |
| SEO         | Search Engine Optimization                         | 搜索引擎优化         | 搜索优化       |
| IDE         | Integrated Development Environment                 | 集成开发环境         | 编程软件       |
| SDK         | Software Development Kit                           | 软件开发工具包       | apt            |
| POC         | Proof of Concept                                   | 概念验证             | 石山代码       |
| ProtoType   | Prototype                                          | 软件原型             | 刚出炉的石山   |

## 2. NLP / AI / 大模型领域

| 缩写词        | 全称                                                    | 含义                               | 口语/真正含义          |
| ------------- | ------------------------------------------------------- | ---------------------------------- | ---------------------- |
| LLM           | Large Language Model                                    | 大语言模型                         | 大模型                 |
| Vibe coding   | Vibe coding（与AI自然交流编程）                         | 心流\AI编程                        | 我不会编程             |
| BERT          | Bidirectional Encoder Representations from Transformers | 双向编码器表示                     | 情感模型               |
| TTS           | Text-to-Speech                                          | 文本转语音                         | 语音合成               |
| OCR           | Optical Character Recognition                           | 光学字符识别                       | 文字识别               |
| MB            | Memory Bank                                             | AI记忆库                           | 记忆银行               |
| MoE           | Mixture of Experts                                      | 混合专家模型                       | 多模型协作             |
| GPT           | Generative Pre-trained Transformer                      | 生成式预训练Transformer            | Chatgpt                |
| Zero-shot     | Zero-shot Learning                                      | 零样本学习（不给例子直接问）       | 我懒得写例子           |
| One-shot      | One-shot Learning                                       | 单样本学习（给1个例子）            | 我能写一个例子         |
| Few-shot      | Few-shot Learning                                       | 小样本学习（给几个例子）           | 我写挺多例子           |
| Multi-shot    | Multi-shot Learning                                     | 多样本学习（给多个例子）           | 跑不好只能多写几个例子 |
| ToT           | Tree of Thoughts                                        | 思维树                             | LLM串起来跑            |
| GoT           | Graph of Thoughts                                       | 思维图                             | 串复杂点跑             |
| RAG           | Retrieval-Augmented Generation                          | 检索增强生成                       | 上下文不足导致的       |
| LoRA          | Low-Rank Adaptation                                     | 低秩适应（高效微调方法）           | 跑涩图用的             |
| QLoRA         | Quantized LoRA                                          | 量化LoRA                           | 我显存不够             |
| Prompt Tuning | Prompt Tuning                                           | 提示微调                           | 写提示词的             |
| PEFT          | Parameter-Efficient Fine-Tuning                         | 参数高效微调                       | 嫌提示词不够的         |
| ONNX          | Open Neural Network Exchange                            | 开放神经网络交换格式               | 嫌pytorch太重的        |
| F1            | F1 Score                                                | F1分数（精确率和召回率的调和平均） | 最好的指标             |
| ACC           | Accuracy                                                | 准确率                             | 最面向结果的指标       |

| 缩写词 | 全称                               | 含义                 | 口语/真正含义        |
| ------ | ---------------------------------- | -------------------- | -------------------- |
| VM     | Virtual Machine                    | 虚拟机               | 主机分身术           |
| VPS    | Virtual Private Server             | 虚拟专用服务器       | 买服务器准备破产     |
| VNC    | Virtual Network Console            | 虚拟网络控制台       | 原主机没GUI          |
| VPN    | Virtual Private Network            | 虚拟专用网络         | 去国外迫害贞操        |
| VPC    | Virtual Private Cloud              | 私有云网络           | 在云上租个保险柜存下一次迫害贞操的东西 |
| WSL    | Windows Subsystem for Linux        | Windows的Linux子系统 | Windows上做Linux开发 |
| IP     | Internet Protocol                  | 网络协议             | 盒                   |
| DNS    | Domain Name System                 | 域名系统             | 记得常刷新           |
| HTTP   | HyperText Transfer Protocol        | 超文本传输协议       | 危险网站             |
| HTTPS  | HyperText Transfer Protocol Secure | 安全超文本传输协议   | 不危险网站           |
| FTP    | File Transfer Protocol             | 文件传输协议         | 传片                 |
| SSH    | Secure Shell                       | 安全外壳协议         | 链接并安全传片       |
| TCP    | Transmission Control Protocol      | 传输控制协议         | 收不到就坏掉！         |

## 4. 见得不多的缩写词

| ------ | ------------------------ | ------------------------------- | ------------------ |
| FE     | Frontend                 | 前端                            | 给用户看的         |
| BE     | Backend                  | 后端                            | 给老板看的         |
| OP     | Operations               | 运维                            | 水工作的           |
| LGTM   | Looks Good To Me         | 我看着没问题（Code Review常用） | 懒得看了，过       |
| PTAL   | Please Take A Look       | 请看一下（PR评论）              | 我求你了你看一眼吧 |
| TL;DR  | Too Long; Didn't Read    | 太长不看                        | 少废话             |
| RTFM   | Read The Fxxking Manual  | 去读那该死的手册                | 不会看文档？       |
| YAGNI  | You Aren't Gonna Need It | 你其实用不着它                  | 过度设计导致的     |
